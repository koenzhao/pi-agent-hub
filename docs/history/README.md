# Historical Notes

This directory archives completed or deferred feature notes from earlier implementation work. These files are useful for understanding why decisions were made, but they are not current product contracts.

For current behavior, use:

- [Features](../FEATURES.md) for dashboard workflows and user-facing behavior.
- [Configuration](../CONFIG.md) for runtime state, Skills, MCP, themes, and config.
- [Structure](../STRUCTURE.md) for contributor architecture guidance.

Historical notes may intentionally mention old package names, commands, state paths, or discarded plans.
