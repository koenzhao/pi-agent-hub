Core UX rule

Scan every row. Expand exactly one.

Unselected sessions remain one line at every width. Subagent trees start collapsed; Space toggles the selected parent between ▸ and ▾, while filters reveal matching children. Selection adds a visible border plus at most one line each for attention, exact phase/task progress, and one action. The authored feature title stays in the header; full phase/action context moves to one deduplicated right-pane work block.

Board notation: PL plan · EX execute · RV review · RF reflect · CM commit. ▐PL▌ marks the active workflow step; ◫1 means the session occupies panel slot 1.

System boundary

Extensions derive context. Hub projects it.

The implementation avoids a dashboard-side workflow parser. Each producer publishes the smallest transient shape it owns; Hub reads two existing state channels and remains a generic consumer.

Decision fence

A supervision view now—not a project manager.

The board is deliberately read-only. Future agent interactions may begin here, but this release proves the information model and responsive UI before adding creation, dispatch or movement controls.

✓ In this implementation

  • Producer-owned ordered workflow steps and friendly labels.
  • Optional generic plan summary from pi-session-summary.
  • Active-workflow lanes with hidden-category counts.
  • Explicit ready/question/blocked markers plus responsive selected-card detail.
  • Existing keys, status, groups, panels and lifecycle behavior.

— Explicitly later

  • Horizontal columns or two-dimensional navigation.
  • Drag/drop, manual stage changes or WIP limits.
  • Creating sessions or dispatching workflow skills from cards.
  • Editing plan tasks or exporting the full checklist to Hub.
  • Persisted board state, card order or registry schema changes.

Decision summary

Enrich selection, not the whole fleet.

The board stays faithful to the app's minimal center: a compact Pi-native session dashboard, with richer context arriving through optional producer contracts rather than new persistent product machinery.
